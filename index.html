Image Relief · Version 2.2

Bring images into dimension.

Turn a grayscale height map into a dimensional slat design. Version 2.2 gives you finer control over the depth, smoothness, and forward position of your imported artwork.

Read the height map directly

Import 8-bit or 16-bit grayscale PNG height maps. Black represents the lowest surface and white projects farthest forward, with grayscale values mapped consistently to height.

Add depth, keep the backing

Increase relief depth while preserving the slat backing. Use Extend to move only the imported subject forward while keeping its internal depth differences intact.

Choose the finishing controls

Fine-tune Pattern Strength and relief depth, then use optional smoothing, contrast, or Invert Depth to suit your map. Preview the changes as you work.

Start with a map or prepare your own

Download an example height map, or copy the app’s AI image-to-depth prompt into your image-generation tool. Import the resulting map when it is ready.

Use a true height map for predictable relief. A shaded grayscale photograph can turn lighting and surface texture into unwanted depth. The importer reads height values; the copyable AI prompt is a separate preparation aid.

Common CNC dimensional art questions.

Quick answers for makers comparing parametric wood slat panel design tools, depth map relief workflows, and CNC-ready export options.

What is a parametric artwork?

A parametric artwork is a dimensional artwork whose shape is controlled by adjustable design values. In a wood slat panel, changing the profile of each slat creates waves, patterns, or image reliefs across the assembled panel. Parametric Studio CNC lets you adjust those patterns, the artwork dimensions, and the slat spacing while previewing the result in 3D.

What is Parametric Studio CNC?

It is browser-based CNC dimensional art software for creating parametric wood slat panels, depth map reliefs, fabrication layouts, and export files.

Can it export files for CNC software?

Yes. The full version exports SVG, DXF, STL, and JSON design files for downstream CAD and CAM workflows.

Can I use depth maps?

Yes. Import 8-bit or 16-bit grayscale PNG height maps to create slat-based relief geometry. Black is lowest and white projects forward. Version 2.2 adds greater depth control while preserving the slat backing, plus subject-only Extend and optional smoothing, contrast, and depth inversion. Use a true height map; a shaded photograph is not necessarily depth data.

Does it work on mobile?

The app is designed for modern desktop browsers. A laptop or desktop computer is recommended for the best experience.

Can I sell things I make with Parametric Studio CNC?
